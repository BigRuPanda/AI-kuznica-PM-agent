# Навигация по релизам и фильтры разборов

## Цель

Открывать оценку выбранного релиза из журнала за один переход и находить связанные разборы в разделе «Разборы».

## Журнал и оценка

- Название релиза в журнале открывает «Оценку релиза», если она доступна. Для остальных записей журнал показывает название и действие «Запланировать оценку».
- В каждой строке есть кнопка «Запланировать оценку». Она открывает форму нового разбора с выбранным релизом.
- Промежуточный экран данных и кнопку оценки с «Обзора» убираем. Ссылка возврата на экране оценки ведёт в «Журнал релизов».
- Старые ссылки на экран данных открывают оценку выбранного релиза, когда она доступна, и журнал в остальных случаях.

## Карточки и фильтры

- Статус и короткие метки типа располагаются над названием. Для разбора по сигналу показываем «сигнал», для связанного с релизом — «релиз». При обеих связях видны обе метки. Для самостоятельного разбора над названием показываем статус.
- Метки рассчитываются из существующих данных разбора. Релиз определяется по привязке разбора или сигнала, его номер виден в карточке.
- На вкладке «Разборы» фильтр «Тип» работает вместе с фильтром «Состояние». Варианты типа — «Все», «Сигналы», «Релизы», «Самостоятельные». Разбор с двумя метками виден в обеих группах.

## Варианты поиска связанных разборов

- Выбран фильтр по типу. В группе «Релизы» видны все разборы, связанные с релизами, и номер на каждой карточке.
- Рассматривался дополнительный список для выбора конкретного релиза. Он сужал бы выборку до одной выкладки и добавлял бы ещё один элемент управления.

## Проверка

Пройти из журнала к оценке и обратно, открыть форму планирования для записи журнала и проверить предвыбранный релиз. Проверить метки, самостоятельные разборы, совмещение фильтров и переходы по старым ссылкам.
