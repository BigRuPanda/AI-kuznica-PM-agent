# Группы чатов и закрепление материалов на странице разбора — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Показывать «Добавить в разбор» только внутри открытого разбора и разделить переписки во вкладке «Чаты» на «Личные» и «Разборы».

**Architecture:** В React видимость действия определяет маршрут, который уже передаёт `caseId` в `MaterialsProvider`. Для списка переписок сервер сопоставляет существующие идентификаторы чатов с доступными разборами пользователя. Клиент группирует результат после поиска.

**Tech Stack:** React 19, TypeScript, Node.js 24, SQLite, node:test, Playwright.

**Spec:** [Требования из запроса, скриншота и уточнения о командных чатах](#global-constraints).

## Global Constraints

- Закрепить материал или снять закрепление можно на странице конкретного разбора `#case/<id>`, включая встроенную переписку и открытые из неё материалы.
- Во вкладке «Чаты» это правило действует и для переписки из группы «Разборы». Прямая ссылка `#material/<id>` открывает самостоятельную страницу материала.
- «Разборы» содержат переписки, созданные для конкретного разбора через `case-thread`. По выбору пользователя все остальные переписки, включая «Команда Store» и общие чаты пользователей, входят в «Личные». Права участников определяются существующим полем `scope`.

## Review Focus

1. Одна переписка на двух страницах. Закрепление доступно только при открытом разборе.
2. Отчёт, вложенный график и прямая ссылка. Предпросмотр, открытие и прикрепление к сообщению работают при скрытых кнопках закрепления.
3. Один материал уже закреплён. В чате скрыты оба состояния кнопки, а на странице разбора снятие закрепления применяется к текущему разбору.
4. Старая переименованная переписка разбора и обычный чат с таким же названием остаются в своих группах. Общие чаты и личный чат по выделению графика входят в «Личные».
5. Поиск находит совпадения в обеих группах, сохраняет текущую переписку и работает в раскрывающемся списке на телефоне.
