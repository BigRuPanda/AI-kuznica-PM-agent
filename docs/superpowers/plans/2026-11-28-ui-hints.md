# Контекстные подсказки на всех экранах — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Покрыть подсказками все экраны основного приложения и добавить один личный переключатель их видимости.

**Architecture:** `UiHintsScope` создаёт один экземпляр подсказки на авторизованное рабочее пространство или форму входа. Цели задают текст через `data-ui-hint` или `HelpMarker`. Окно показывается через React-портал и ручной popover в верхнем слое браузера, в том числе внутри открытого диалога.

**Tech Stack:** React 19, TypeScript, CSS, Popover API, `localStorage`, Node.js 24, pnpm, Playwright.

**Spec:** [Дизайн, охват и тексты](../specs/2026-11-28-ui-hints-design.md).

## Global Constraints

- Область применения — все экраны основной сборки из `web/team.tsx`, включая вход, регистрацию, списки и пустые состояния, редакторы, сохранённые результаты, аналитику релизов и диалоги. На каждом экране есть хотя бы одна местная подсказка.
- Первая версия использует существующие React, TypeScript, CSS и `localStorage`.
- Подсказка открывается через 250 мс наведения мышью или сразу при фокусе с клавиатуры. Значок `?` служит целью наведения и фокуса. Нажатия мышью и касания выполняют обычное действие элемента.
- Одновременно видна одна подсказка. Окно связано с целью через `aria-describedby`. Курсор можно перевести на окно, чтобы дочитать текст.
- Уход курсора закрывает окно через 140 мс. Escape, потеря фокуса, переход на другой экран и исчезновение цели закрывают окно и отменяют ожидающий показ.
- Окно находится над целью с зазором 8 px. При нехватке места сверху окно появляется снизу. Отступ от края видимой области составляет минимум 8 px. Стрелка указывает на цель.
- Появление занимает 150 мс. Окно поднимается на 4 px и проявляется. При `prefers-reduced-motion: reduce` применяется показ без анимации.
- Непрозрачность фона и стрелки составляет 92%. В светлой теме фон `rgb(37 35 42)` и белый текст. В тёмной теме фон `rgb(242 238 244)` и текст `#222026`.
- «Настройки → Мои настройки» содержит переключатель «Показывать подсказки». По умолчанию он включён. Он скрывает окна и значки `?` на всех экранах текущего аккаунта.
- Настройка хранится отдельно для каждого аккаунта в браузере. На входе и регистрации подсказки включены по умолчанию.
- Тексты и доступные имена брать из таблиц. Условия доступа определяет текущий экран по роли, данным и видимости интеграции.

## Review Focus

1. Узкое боковое меню и меню у верхнего края. Окно целиком помещается в видимую область, а стрелка указывает на цель. Задача 1.
2. Уход с цели до 250 мс и переход между её иконкой и подписью. Ожидающий показ отменяется, а открытое окно продолжает относиться к той же ссылке. Задача 1.
3. Смена аккаунта в одном браузере и экран входа. Каждый аккаунт получает свою настройку, на входе доступна подсказка о приглашении. Задача 2.
4. Открытый диалог и два последовательных нажатия Escape. Первое закрывает подсказку, второе закрывает диалог и возвращает фокус к его кнопке. Задача 3.
5. Сохранённые ссылки разных форматов и права жюри. Подсказка отражает результат, который действительно открылся, и следует правилам видимости демо. Задачи 5 и 6.
