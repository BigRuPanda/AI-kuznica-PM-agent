# Постоянная панель агента в «Разборе релиза»

> Реализация по шагам через `superpowers:executing-plans`. Отмечать выполненные шаги в списке.

**Цель**

Показывать чат выбранного релиза сразу. На компьютере он закреплён справа, на телефоне расположен под заголовком.

**Архитектура**

`ReleaseDecision` управляет загрузкой среза и подключением переписки через `release-thread`. CSS-сетка размещает один экземпляр `Chat` в доступной панели. Закрепление и высоту окна определяет существующий `useDiscussionDock`.

**Стек**

React, TypeScript, CSS Grid, Playwright.

**Дизайн**

[Окно агента в «Разборе релиза»](../specs/2026-11-28-release-agent-panel-design.md)

## Ограничения

- Меняется экран `#release-decision/:id`, который открывается из журнала релизов.
- Раскладка следует текущей границе приложения. До 820 px включительно чат под заголовком, начиная с 821 px чат справа.
- Действия по задаче доступны для текущего среза и остаются в колонке разбора. Запись подтверждается существующим действием.
- Работать в `main-copy-2026-11-28`. Сверять ветку с `origin` перед правками, в ходе работы и перед пушем. Новые коммиты коллег подтягивать сразу. После проверки изменений отдельно запросить разрешение на пуш.

## Что проверить

- Прямой вход и переход из журнала сразу показывают нужную переписку.
- Правая панель оставляет поле ввода видимым при прокрутке и верхнем меню.
- На ширине 390 px панель следует сразу за заголовком, горизонтальной прокрутки страницы нет. На границе 820–821 px раскладка переключается.
- При быстром переключении семейства ответ старого запроса не меняет чат нового семейства.
- При смене даты вопрос получает новый срез. Повторный вход сохраняет историю, а срез без выпущенной функции и ошибка загрузки показывают статус в панели.

## Задача 1. Открытие и размещение панели

**Файлы**

- `web/release-decision.tsx` — раскладка страницы и загрузка переписки.
- `web/release-decision.css` — две колонки на компьютере и одна на телефоне.
- `web/team.tsx` — передача заголовка «Чат разбора · <номер релиза>» в `Chat` для этого маршрута.
- `tests/workspace.browser.mjs` — обновление сценария `release decisions preserve the historical cutoff, cited cells and manual issue write`.
- `README.md` — актуальное описание перехода к чату на экране «Разбор релиза».

**Интерфейсы**

`post<{ id: string }>('release-thread', { product, releaseId, decisionContext })` возвращает идентификатор личной переписки. `ReleaseDecision` передаёт его в существующий `renderChat(thread, caseId, releaseId, product, decisionContext)`. `Chat` принимает дополнительный необязательный `title?: string` для заголовка переписки.
