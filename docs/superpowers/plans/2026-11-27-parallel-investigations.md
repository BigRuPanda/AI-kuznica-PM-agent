# Параллельные ИИ-проверки и повтор этапа — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Автоматически запускать независимые ИИ-проверки разных разборов в пределах общего настраиваемого лимита и повторять только неудавшийся этап.

**Architecture:** SQLite каждого пространства хранит снимок исследования, зависимости и состояние попыток. Один диспетчер в процессе приложения распределяет места между пространствами и разборами. Интерфейс читает состояние ролей с сервера и передаёт номер неудавшейся попытки при ручном повторе.

**Tech Stack:** Node.js 24, node:sqlite, React 19, TypeScript, node:test, Playwright, pnpm.

**Spec:** [Утверждённая спецификация](../specs/2026-11-27-parallel-investigations-design.md).

## Global Constraints

- База реализации — `0e1d08d` или её потомок. В изолированной рабочей копии объединить актуальную базу с коммитами спецификации и плана. Проверить `git merge-base --is-ancestor 0e1d08d HEAD`. Именно в этой версии уже работает веб-поиск личных альтернатив.
- Поле «Максимум одновременных ИИ-проверок» в «Настройки команды» → «Исследования по сигналам». Начальное значение **10**. Общий бюджет на все пространства одного экземпляра. Снижение лимита позволяет уже начатым запросам закончить.
- Режимы «По ролям», «Ведущий и рецензент», «Только ведущий» сохраняют своё значение. Личные поручения используют действующие правила наследования режима и доступа к источникам.
- «Повторить ИИ-проверку» действует на конкретную неудавшуюся роль. История, готовые результаты, стоимость запросов, идентификаторы и ссылки на расчёты сохраняются.

## Review Focus

1. Пороговый сигнал без релиза попадает на расчёт после обновления, в том числе при отсутствии полного базового периода.
2. Перезапуск со старыми записями, поздний ответ или смена ревизии не создают второй результат и не стирают первый.
3. Одновременные роли личной альтернативы получают один и тот же снимок и одну сохранённую выборку внешних источников.
4. Без клиентов в браузере очередь заполняет 10 мест и распределяет их между разборами. Снижение лимита при занятых местах работает и для пространств жюри.
5. Два клика и автоматический таймер, попавшие на одну ошибку, запускают одну новую попытку. Пользователь соседнего пространства и читатель чужого личного исследования не могут её инициировать.
