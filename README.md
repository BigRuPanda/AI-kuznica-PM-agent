# Помощник продакта Softline Store

Приложение отслеживает изменения продуктовых метрик, помогает разобраться в причинах и проверить эффект релиза. Расчёты хранятся вместе со ссылками на данные.

## Быстрый запуск

Понадобятся Node.js 24 и pnpm 11. Для импорта ZIP, XLSX и PPTX и отправки почты нужен Python 3.10+.

```sh
pnpm install --frozen-lockfile
pnpm setup
pnpm build
pnpm start
```

Выберите **У меня есть приглашение** и введите код `ADMIN_INVITE_KEY` из файла `.env`. После регистрации администратор выдаёт приглашения в настройках команды. [Открыть приложение на порту 8090](http://127.0.0.1:8090)

## Данные и разборы

1. В разделе **Источники** загрузите ZIP, XLSX или PPTX и нажмите **Загрузить и пересчитать**.
2. Откройте нужный релиз или сигнал. В разборе можно сверить метрики, выбрать период и задать вопрос помощнику.
3. Подтвердите черновик задачи и задайте условия проверки эффекта после выкладки.

CSV с событиями загружается через **Релизы → Управление**. В этом же меню можно создать релиз на основе загруженных событий.

## Модель и интеграции

По умолчанию `DATA_PROFILE=local` оставляет расчёты на сервере и отключает вызовы модели. Чтобы подключить Qwen3.8 27B через ProxyAPI, укажите в `.env` следующие параметры.

```dotenv
DATA_PROFILE=configured
LLM_BACKEND=proxyapi
LLM_MODEL=qwen/qwen3.8-27b
```

Введите токен командой `pnpm model:key`. Она скрывает ввод и сохраняет ключ в `.env`. Проверьте подключение командой `pnpm model:check` и перезапустите приложение.

Учётные данные Метрики, Telegram и SMTP задаются в `.env`. Подключения Redmine и Confluence доступны в настройках приложения. [Шаблон настроек](.env.example) · [Signal Bridge](integrations/signal-bridge/README.md)

Для клиента MCP выпустите ключ в **Моих настройках**. Используйте маршрут `/mcp` с заголовком `Authorization: Bearer <ключ>`.

## Хостинг на VPS

Установите Docker с Compose, направьте DNS на VPS и откройте порты 80 и 443. Caddy настроит HTTPS.

При первом развёртывании создайте `.env` командой `install -m 600 .env.example .env`. Укажите домен в `SITE_DOMAIN` и полный HTTPS-адрес в `APP_BASE_URL`. Для `ADMIN_INVITE_KEY` сгенерируйте случайный код командой `openssl rand -hex 32`.

```sh
docker compose up -d --build
docker compose ps
curl -fsS https://pm.example.com/health
```

Подставьте свой домен в проверку `/health`. У `app` должен быть статус `healthy`. Команда `docker compose exec app node scripts/ops.mjs links` покажет приглашение для регистрации.

SQLite хранится в томе `pmdata`. Перед обновлением сохраните копию командой `docker compose exec app node scripts/ops.mjs backup`.
