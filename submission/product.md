# Помощник продакта Softline Store

Продакт получает сигнал об изменении продуктового показателя, задаёт уточняющий вопрос и видит расчёт, его период и источники. Команда может опубликовать вывод, записать задачу в бэклог и назначить дату проверки после выпуска исправления.

## Как работает приложение

1. Администратор импортирует агрегаты, недельные продажи, релизный календарь, задачи и качественные исследования. Рабочее пространство хранит версии данных и ссылки на ячейки и слайды.
2. Сервер проверяет пороги справочника для индекса заказов и сравнивает последние четыре полные недели с предыдущими двенадцатью. Повторное отклонение создаёт одно уведомление. В неполном окне остаётся видна причина ограничения данных.
3. Модель выбирает инструменты анализа. Сервер вычисляет числа, формирует источники и сохраняет версию результата. В личном чате можно менять состав карточек и фильтры. При публикации продакт видит вывод, получателя и список выбранных материалов.
4. Из разбора можно найти существующую задачу, подготовить и подтвердить создание или смену приоритета. После выкладки проверяются согласованный уровень восстановления и контрольный продукт.

## Поставка и проверка

React, TypeScript, Node.js, SQLite, Python для разбора Office и SMTP, MCP для внешних клиентов. Модель подключается через Gemini, Vertex или совместимый API с инструментами. Состав конфигурации, команды запуска, порядок подключения Метрики, Redmine, Confluence Cloud и Data Center и каналов доставки приведены в [README](../README.md).

Конкурсные дополнения включают аккаунты, изоляцию жюри, личные и групповые чаты, импорт документов с адресами источников, самостоятельный детектор, публикации, задачи и наблюдение за эффектом. За основу взят существовавший прототип аналитики релизов с CSV, SQLite, React и локальным MCP. Исходное состояние доступно в первом коммите истории.

Приёмка проходит локально в независимых браузерных профилях. Внешние Метрика, Redmine, Confluence, почтовый сервер и Telegram проверяются на конкретных учётных данных при подключении. Подготовлены контейнер и конфигурация HTTPS для последующего размещения на VPS. На демо с локальными задачами и страницами действие явно помечено в интерфейсе.

[Редактируемый расчёт стоимости запроса](request-cost.xlsx) содержит токены и задержку из реального прогона, формулы и изменяемый бюджет инфраструктуры. Источники организатора, файлы аккаунтов и видеозапись на конкурсных данных хранятся отдельно от публичного кода.
